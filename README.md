# OneDayPOS เว็บตัวจริง

ระบบขายหน้าร้านแบบเต็ม สำหรับคาเฟ่และเบเกอรี่
มีหน้าเข้าสู่ระบบ แอดมิน ผู้ขาย สต๊อก และรายงาน

เปิดใช้ได้ที่
https://jungeiei.github.io/OneDayPOS-WEB/

เดโมทดลองใช้ (ไม่มีแอดมิน) อยู่คนละที่
https://jungeiei.github.io/OneDayPOS-DEMO/

## บัญชีเริ่มต้น

| บทบาท | ชื่อผู้ใช้ | รหัสผ่าน |
|---|---|---|
| แอดมิน | admin | admin |
| ผู้ขาย | somchai | 1234 |
| ผู้ขาย | somying | 1234 |

เข้าแอดมินแล้วควรเปลี่ยนรหัสผ่าน

## แอดมินทำอะไรได้

- เพิ่ม แก้ไข และปิดเมนู จัดหมวดหมู่
- เพิ่มผู้ใช้ กำหนดเป็นผู้ขายหรือแอดมิน
- ตั้งชื่อร้าน ที่อยู่ เบอร์โทร และโลโก้บนใบเสร็จ
- เปิดหรือปิดการรับโอนและบัตร
- กำหนดว่าผู้ขายยกเลิกบิลของตัวเองในวันเดียวกันได้หรือไม่
- ดูประวัติการใช้งาน สำรองข้อมูล และส่งออกเมนู

## ข้อมูลอยู่ที่ไหน

ข้อมูลการขายอยู่บนเบราว์เซอร์ของเครื่องนั้น
เครื่องอื่นเปิดลิงก์เดียวกัน จะไม่เห็นบิลของกันและกัน
